# VitroCAD

Единое приложение для трёх инженерных утилит VitroCAD.

## Разделы

- **Структура папок** — создание структуры проекта из Excel.
- **Права доступа** — назначение прав по Excel-матрице.
- **План-график** — синхронизация план-графика из Excel.

## Интерфейс

Версия 1.2.0 перестроена по интерфейсной системе референсного Larix Platform Plugin:

- одна общая авторизация над всеми рабочими разделами;
- один логин получает токен и передаёт его всем трём инструментам;
- верхняя навигация одинаковыми вкладками без лишних иконок;
- карточки, поля, таблицы, кнопки, отступы и скругления из Larix UI;
- тот же оранжевый акцент `#F7921E`;
- тот же набор иконок из `assets/`;
- единый переключатель светлой/тёмной темы;
- один общий блок «Открыть лог» снизу, открывающий журнал текущего раздела;
- старые внутренние шапки и отдельные блоки авторизации больше не отображаются.

Служебные поля старых модулей сохранены внутри программы для совместимости с существующей бизнес-логикой, но из основного интерфейса убраны.

## Запуск

```bat
run.bat
```

Перед первым запуском установить зависимости:

```bat
py -m pip install -r requirements.txt
```

## Сборка EXE

```bat
build.bat
```

Результат:

```text
dist\VitroCAD.exe
```

Все изображения из `assets/` включаются в единый EXE автоматически.
