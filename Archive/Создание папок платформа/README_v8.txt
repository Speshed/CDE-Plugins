v8 — исправление выпадающих списков в тёмной теме

1. Цвет текста popup QComboBox теперь определяется по QApplication.larix_dark,
   поэтому текст остаётся читаемым при наведении/выборе во всех ComboBox.
2. У popup удалено внешнее скругление QListView, из-за которого просвечивал
   белый системный контейнер в углах.
3. Фон QListView/viewport/private container принудительно синхронизирован с темой.
4. Скругление сохранено у самих строк списка, поэтому мягкий hover остаётся.
