Larix Manager — redesign v5

Изменения этой версии:
- убраны дублирующие внутренние заголовки карточек (Ролевая матрица / Папочная структура / Пользователи / Проект и папки / Импорт в Larix);
- Excel-карточки начинаются сразу с понятного блока Excel-файла;
- очищены все кнопки от текстовых псевдоиконок (+, стрелок, галочек и т.п.); используется только одна настоящая PNG-иконка;
- загруженный файл отображается с одной иконкой check, кнопка загрузки — с одной иконкой upload;
- исправлен переключатель Новый проект / Добавить папки: мягкая подсветка как у обычных кнопок, без яркой линии;
- добавлена легенда статусов импорта: Успешно / Уже добавлен / Ошибка;
- после импорта выводится краткая сводка последнего запуска;
- Открыть лог использует одну иконку;
- сохранены фирменные мягкие hover/pressed-состояния, Segoe UI и скроллбары.

Главный файл: Larix_User_Platform.py
Тема: larix_ui_theme.py
