# SGNL Platform — styled UI

Обновлённая версия `SIGNAL.py` с единым интерфейсом для настройки проекта SGNL.

## Разделы

### Ролевая матрица
- выгрузка готового Excel-шаблона с примерами и легендой прав;
- выбор Excel и листа;
- предварительная сверка с актуальными правами SGNL;
- точное применение П / С / З / Р;
- снятие прав по `-`;
- пропуск уже совпадающих записей.

### Папочная структура
- выгрузка отдельного Excel-шаблона иерархии;
- чтение колонок `Уровень N` из Excel;
- предварительная сверка структуры;
- создание только отсутствующих папок;
- существующие папки не удаляются.

### Атрибуты
- выгрузка Excel-шаблона с колонками «Название / Тип / Область / Обязательный / Значения списка» и выпадающими значениями;
- обязательный сценарий: скачать актуальный шаблон, заполнить лист «Атрибуты»,
  загрузить файл, выполнить отдельный предпросмотр и только затем создать атрибуты;
- ошибки структуры и строк блокируют создание всего файла и отображаются в таблице предпросмотра;
- уже существующие активные атрибуты пропускаются по имени без учёта регистра и
  помечаются как «Уже существует»;

Функционал добавлен по запросам из `Атрибуты.har`:

- чтение списка: `POST /api/attributes/types/find`;
- создание: `PUT /api/attributes/types`;
- типы: **Текст (`Text`)**, **Да/Нет (`Bool`)**, **Дата (`Date`)**, **Список (`List`)**;
- `isRequired` — обязательность атрибута;
- `dataType`: без значения, `Item` или `Folder`;
- для `List` поддерживается упорядоченный набор вариантов;
- можно подготовить несколько атрибутов в Excel и создать их одной операцией;
- перед созданием список повторно читается из SGNL, активные дубликаты по имени пропускаются.

Раздел атрибутов использует общую авторизацию и выбранный проект. Excel-файл
обязателен: без успешного предпросмотра создание недоступно. После изменения
файла или проекта требуется повторить предпросмотр.

## Интерфейс

- одна карточка авторизации для всех разделов;
- выбор компании и проекта сразу после входа;
- `Docs URL`, `Hub URL` и `access_token` скрыты в **Служебных параметрах**;
- вкладки **Ролевая матрица / Папочная структура / Атрибуты**;
- светлая и тёмная темы;
- карточки, скругления, оранжевый акцент, hover/pressed-состояния;
- иконки и визуальный язык перенесены из референсного проекта;
- тема вынесена в `sgnl_ui_theme.py`.

## Структура

```text
Larix CDE/
├─ app/plugins/signal/           # SIGNAL: API, Excel-логика и окно
├─ app/assets/                   # изображения и иконки интерфейса
├─ config/requirements.txt       # зависимости
├─ tools/                        # проверки и сборка
├─ run.bat
├─ install_dependencies.bat
└─ build_single_exe.bat
```

## Запуск

```bat
install_dependencies.bat
run.bat
```

Либо запустить напрямую: `py app/launcher.py`.

## Сборка EXE

Из корня репозитория запустить `build_single_exe.bat`. Результат появится в
`release\Larix_CDE.exe`.

## Сохранённый функционал

При добавлении раздела атрибутов существующие классы и методы исходной styled-версии не удалялись. OAuth/CAPTCHA, загрузка компаний и проектов, Excel-парсер, создание папок, предпросмотр и синхронизация прав сохранены.

## Excel-шаблоны

На каждой вкладке есть своя кнопка **«Скачать шаблон Excel»**. Файл формируется непосредственно программой через `openpyxl` и сохраняется в выбранное пользователем место.

- **Ролевая матрица** — уровни папок, колонки ролей, легенда `П / С / З / Р / -`, выпадающий список допустимых прав.
- **Папочная структура** — уровни `Уровень 1...N` и примеры наследования пустых ячеек.
- **Атрибуты** — название, тип, область, обязательность, значения списка; для ограниченных полей добавлены выпадающие списки.

Во всех шаблонах рабочий лист идёт первым, а вторым добавлен лист **«Инструкция»**.
